# Interactive rating component

![Design preview for the Interactive rating component challenge](./design/desktop-preview.jpg)

Solution to the Frontend Mentor **Interactive rating component** challenge - a responsive component built from the provided design.

**Live demo:** https://erfan-revenant.github.io/Interactive-rating-component/

## Built with

- Semantic HTML5
- CSS custom properties, Flexbox and media queries
- Vanilla JavaScript for the interactive behaviour (no framework, no build step)
- Bundled webfonts and SVG assets from the challenge starter files

## Run locally

```bash
git clone https://github.com/ErfanBagheri404/Interactive-rating-component.git
cd Interactive-rating-component
```

Open `index.html` in a browser. Nothing to install or compile.
